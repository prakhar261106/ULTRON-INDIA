ULTRON Deep Learning Forecasting Engine

Purpose:
Forecast short-term intraday price movements using machine learning and deep learning.

Main responsibilities:
- Historical market data preparation.
- Feature engineering.
- Baseline model development.
- LSTM forecasting.
- Transformer experiments.
- Multi-horizon forecasting.
- Model training.
- Model validation.
- Walk-forward evaluation.
- Prediction uncertainty.
- Model performance tracking.

Output:
Forecast direction, prediction, uncertainty and model validation status.

Important:
Models must be evaluated against simple baselines before being considered useful.
